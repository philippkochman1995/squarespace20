Bei vielen Squarespace Rabatten musst du beim Bezahlen einen Aktionscode eingeben. Hier funktioniert es anders: studio vis erstellt über sein Squarespace Circle Gold Partnerkonto eine berechtigte Test-Website, mit der der Rabatt von 20 % verknüpft ist.

Website mit Rabatt erstellen Ablauf ansehen

So erhältst du den Rabatt ohne Code

  1. 01

    E-Mail und Vorlagen-Link senden

    Verwende den Link einer offiziellen Squarespace Vorlage oder lass das Feld für eine leere Website frei.

  2. 02

    Squarespace Einladung annehmen

    Squarespace sendet dir eine Einladung, nachdem die Test-Website erstellt wurde.

  3. 03

    Jährliche Zahlung wählen

    Das Angebot von 20 % gilt für die erste Zahlung eines berechtigten jährlichen Website-Tarifs.

Häufige Fragen zum Aktionscode

Ist das ein Squarespace Aktionscode?

Nein. Es ist ein Circle Gold Partner Rabatt, der mit einer neuen berechtigten Test-Website verknüpft ist.

Kann ich ihn mit einem anderen Aktionscode kombinieren?

Nein. Squarespace Rabattangebote können normalerweise nicht kombiniert werden.
